# Model

Download `deepwind-lidar.onnx` from the **Assets** section of [GitHub Releases](https://github.com/EanLeslie/DeepWind-LiDAR/releases) and place it in this directory:

```text
models/
├── README.md
└── deepwind-lidar.onnx
```

The inference script uses this location by default. The ONNX file is distributed through Releases and is excluded from Git tracking.
